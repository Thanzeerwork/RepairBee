3. Universal CORS Policy Resolution:

     to support Vercel preview and production environments (*.vercel.app).

   - Added vercel.json rewrite rules to both web projects to prevent 404s on 
     page refreshes and direct URL navigation.
5. Production Mobile API Targeting:
   - Updated mobile Axios client to automatically target the live Render cluster
     in production environments.
6. Swiggy-Style Live Interactive Map Engine:
   - Eliminated mock SVG canvas drawings from mobile app and upgraded web tracker.
   - Integrated CartoDB Voyager pastel street tiles, real city road network polyline,
     and animated delivery partner scooter with pulsing radar waves and speed tags.
7. Mobile Auth Persistence & Offline-First Hydration:
   - Built unified storage layer with AsyncStorage fallback for web and Expo environments.
   - Fixed premature session deletion during backend boot-up and cold starts.
   - Persisted serialized user profile and auth tokens with non-destructive background sync.
8. Official Mapbox API Integration:
   - Configured active Mapbox access token across mobile, web, admin, and backend environments.
   - Upgraded mobile and web live runner maps to high-resolution Mapbox Navigation Day
     and Satellite Streets @2x Retina vector tiles.
   - Enhanced location picker with Mapbox Streets v12 styling.
9. Real-Time Socket.io Two-Way Messaging & Runner Telemetry Link:
   - Built mobile Socket.io manager (src/api/socket.ts) with unified token authentication.
   - Connected mobile Chat screen (app/chat/[orderId].tsx) for real-time incoming messages,
     typing indicators, haptic alerts, and live sync badges.
   - Upgraded mobile Live Tracking (app/tracking/[orderId].tsx) & SwiggyLiveMap to receive
     real-time physical GPS broadcasts (socket.on('runner_location')) with seamless fallback.
   - Added tracking room telemetry events (join_tracking, runner_location_update) to backend
     gateway (chat.gateway.js) and deliveries service.
10. Native Push Notifications & Alert Dispatcher Pipeline:
   - Installed expo-notifications and expo-device with custom Android channels (orders, telemetry, general).
   - Built mobile notification utility (src/utils/notifications.ts) for foreground banners and FCM/APNs token syncing.
   - Connected notification response deep-linking in app/_layout.tsx to navigate directly to quotes or orders.
   - Added device push token API endpoint in client.ts and flexible token handler in backend users controller.
   - Enhanced Notifications screen (app/notifications.tsx) with live OS push service status and test push trigger.
11. Google Sign-In via Expo AuthSession:
   - Installed expo-auth-session, expo-crypto, and expo-web-browser.
   - Configured custom scheme (`repairbee://`) and created `src/utils/googleAuth.ts` with `useGoogleAuth` hook.
   - Connected WebBrowser session completion (`WebBrowser.maybeCompleteAuthSession()`).
   - Built official 4-color `GoogleLogo.tsx` SVG component.
   - Connected Google Sign-In buttons in both `LoginScreen` (login.tsx) and `RegisterScreen` (register.tsx).
   - Updated `authStore.ts` and `client.ts` to accept either `idToken` or `accessToken`.
   - Updated backend `auth.service.js` and `auth.validators.js` to verify Google OAuth tokens via Google's official public OIDC endpoints (tokeninfo & userinfo) and Firebase fallback.
